# Installation and Deployment

[Español](INSTALL.md) | [English](INSTALL.en.md)

[Home](../README.en.md) · [Project](PROJECT.en.md) · [User guide](USER_GUIDE.en.md)

**The VMware OVA appliance is the main CENTAURUS distribution.** Choose the appropriate mode below; each guide contains its requirements, preparation and detailed procedure.

## 1. VMware OVA — main distribution

Prebuilt appliance with the framework, tools and local model ready to use. This is the starting point for running CENTAURUS in a virtual machine.

[OVA deployment](DEPLOYMENT_OVA.en.md)

## 2. Bootable USB image

A complete disk image for booting the appliance from USB on compatible hardware. Data persists on the media itself.

[USB deployment](DEPLOYMENT_USB.en.md)

## 3. Git + Docker on Linux

An alternative for building and deploying CENTAURUS from the repository on a Linux host, with administrator-managed images and persistent directories.

[Git + Docker deployment](DEPLOYMENT_GIT_DOCKER.en.md)

## 4. Local Core on Windows

An option for development and local Core execution. Its scope differs from the complete appliance and does not guarantee parity across all tools.

[Windows deployment](DEPLOYMENT_WINDOWS.en.md)
